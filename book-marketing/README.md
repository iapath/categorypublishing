# /book-marketing

Serves at **categorypublishing.com/book-marketing**.

Drop the page in as `index.html`, images in `assets/`. No build step — Netlify
publishes this folder as-is, the same way `/articles/` and `/blueprint` work.

| Put | Where |
|---|---|
| The page | `book-marketing/index.html` |
| Images | `book-marketing/assets/` — reference as `assets/<name>` |
| Extra CSS/JS | `book-marketing/` — reference as `<name>.css` |

Lowercase filenames with hyphens. `Hero-Image.PNG` works on a Mac and 404s on
Netlify.

Delete this README once the page is in.
